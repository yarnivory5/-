# 邓希杰 · 个人宇宙

当前网站是独立的 HTML/CSS/JavaScript 静态站点。`site.html` 是页面结构，`app/globals.css` 是样式，`public/galaxy.js` 包含章节内容、动画和相册交互。原有框架文件保留，但当前发布不依赖框架安装。

## 构建

运行 `node scripts/make-static.cjs`，发布 `dist/` 目录即可。

## 动画与交互

参考演示素材的阶段顺序：
1. 首页：姓名为视觉重点，星云缓慢转动。
2. 全景：镜头拉向中心，五个节点展开。
3. 悬停：突出选中节点，降低其他节点亮度。
4. 进入章节：文字淡出、镜头旋转推进，再浮现章节内容。
5. 章节切换：背景色与粒子形态连续变化，保持统一的镜头运动。
6. 相册：手动轮播、圆点选择、左右键、手机横向滑动；照片可看大图。
7. 返回：镜头拉回全景。浏览器前进/后退可恢复章节。

支持减少动态偏好、背景动效暂停、原生视频控件、键盘导航和 Esc 关闭大图；离开章节和隐藏页面时暂停视频。快速导航按最新选择收敛，避免叠加多个内容页。

2026-11-10：依据抖音参考录屏及生活素材完成整体改版。

2026-11-10 滚动版更新：所有章节按首页、全景、关于我、奔跑、笔墨、生活、听我说连续排列。使用原生滚轮和触屏滚动，不拦截滚动；锚点导航支持直达章节。增加阅读进度条、按需加载媒体和移出视口暂停视频。鼠标控制星云视差、倾斜、局部粒子排斥与光晕，平滑插值避免突然跳变；减少动态偏好和暂停开关仍有效。本次按用户要求暂不更新 GitHub。

## 圆柱相册与鼠标光影
照片以 CSS 3D 圆柱轮播呈现，支持按钮、侧面照片、键盘方向键和手机横向滑动。正面照片可点击放大，视频保留原生控制。鼠标光晕独立于自动背景动画；系统减少动态效果时仍保留直接光影响应，手动暂停可关闭。


## 连续弧面更新
背景动效默认开启，仍可手动暂停。关于我只保留个人介绍和肖像。跑步、生活共用 11 张照片序列，从各自入口开始，首尾循环；鼠标左半区预览下一张，右半区预览上一张，按钮、方向键与滑动遵循同一空间方向。照片使用 24 段连续弧面呈现，切换采用 1.15 秒缓动。


## 边缘自动翻页
弧面细分为 48 段。鼠标停留照片展示区左侧 20% 时向下一张翻页，右侧 20% 时向上一张翻页；首次等待 650ms，持续停留每 1500ms 翻页。中间区域、离开、滚动、窗口失焦、隐藏标签页或打开大图时停止。手机保留手动滑动。


## 平滑翻页
翻页角度与鼠标预览角度使用独立注册 CSS 属性，避免鼠标移动重启主翻页过渡。翻页 1.4 秒，预览跟随 0.55 秒，透明度 1.1 秒，自动连续翻页间隔 1.9 秒。默认开启动效模式下修正旧减少动态样式对过渡时长的覆盖；暂停开关仍可关闭动效。
