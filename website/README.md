# 邓希杰 · 我的个人宇宙

基于用户提供的网页演示录屏设计：黑色背景、蓝紫粒子星云、四个环绕节点和弹窗详情。

内容来自用户的自我介绍视频；图形为代码绘制，未使用参考网站的品牌、文字或素材。

编辑 site.html、app/globals.css、public/galaxy.js 后，执行 node scripts/make-static.cjs 生成 dist/。

四个栏目：关于我、马拉松、书法、视频。支持键盘导航、Escape 关闭、暂停动效及系统减少动画偏好。手机减少粒子数量，限制画布像素密度与帧率；隐藏页面停止动画，关闭详情暂停视频。
